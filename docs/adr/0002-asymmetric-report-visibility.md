# Vis mindre om funn enn om savnede sykler

Status: proposed — this applies only if Hjulspor hosts its own reports.

En funnrapport kan peke på en sykkel som fortsatt er tilgjengelig der den ble sett, så offentliggjøring av bilde, nøyaktig sted eller rammenummer kan gjøre falske krav enklere.
Savnetrapporter kan vise flere kjennetegn for å hjelpe findere å kjenne igjen sykkelen, mens funnrapporter bare viser overordnede opplysninger offentlig.
Begge rapporttyper kan lagre rammenummer privat, og kontakt går via Hjulspor uten å vise e-postadresser som standard.
