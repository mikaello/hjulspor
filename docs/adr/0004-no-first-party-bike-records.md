# Ikke lagre sykkelopplysninger i første versjon

Status: accepted.

Hjulspors første versjon skal ikke kreve konto eller lagre rammenummer, bilder, nøyaktig sted eller egne savnet- og funnrapporter.
Besøkende utfører søk på de eksterne tjenestenes egne sider.
Dette begrenser personvernansvaret og gjør det mulig å teste veiviserens verdi før Hjulspor eventuelt oppretter et eget register.
